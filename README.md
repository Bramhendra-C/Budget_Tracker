The Ledger — Personal Budget Tracker

A mobile-friendly web app to track income and expenses. Store data locally, view analytics, and manage your budget with ease.

🚀 Features

Local (offline) mode — data stored in the browser (no server required)

Add transactions (income / expense) with description, date/time, and a category

Dashboard: view net balance, total income, total expense

Analytics:

Trends over day/week/month/year

Breakdown by category (income vs. expenses)

Recent transactions list + “view all” filter

Category filtering

🛠️ Getting Started / Installation

To run this project locally:

Clone the repo:

git clone <repository-url>


Move into the project folder:

cd Budget_Tracker


Open the index.html file in your browser (e.g. via a live-server or double-click).

Since it works in local mode, you don’t need a backend or database — it works entirely client-side.

✅ Usage / How It Works

Open the app in your browser.

On the dashboard, you’ll see your net balance, total income, total expense (initially zero). 
bramhendra-c.github.io

Use Quick Add Transaction to:

Enter amount

Choose type: Expense (−) or Income (+)

Enter description (optional)

Select date & time (optional)

Choose a category (e.g., Food, Transportation, Salary, etc.)

Click Confirm Transaction

That transaction appears in Recent Transactions.

Move to Analytics / Dashboard to see:

Trend charts (day/week/month/year)

Expense & Income breakdowns by category

Use filters / “View All” to search or filter by category/time period.
