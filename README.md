# 💰 The Ledger — Smart Budget Tracker  

> A clean, responsive, and intelligent web app to **track your income and expenses** effortlessly.  
> Designed to help you stay on top of your finances — **anytime, anywhere.**

🌐 **Live Demo:** [Budget Tracker](https://bramhendra-c.github.io/Budget_Tracker/)

---

## ✨ Overview  

**The Ledger** is a modern, browser-based **personal finance manager** built using HTML, CSS, and JavaScript.  
It helps users log daily transactions, visualize spending patterns, and manage their budget — all with **local storage persistence** (no backend required).

---

## 🚀 Features  

✅ **Add, Edit & Delete Transactions** — manage income and expenses easily  
📊 **Interactive Dashboard** — view balance, income, expenses in real time  
📈 **Analytics & Charts** — track financial health across time periods  
🧮 **Category Filters** — analyze spending by categories  
💾 **Offline Support** — data saved securely in browser’s LocalStorage  
📱 **Responsive UI** — optimized for mobile, tablet, and desktop  
🎨 **Minimal & Elegant Design** — focus on simplicity and clarity
